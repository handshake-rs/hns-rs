# hns-odoh-protocol

RFC 9230 ODoH records and draft Handshake P2P ODoH wire types.

This crate provides bounded configuration, message, cryptographic envelope, and
transport values for draft HIP #77.

**The associated Denuo wire assignments are experimental and are not official
Handshake protocol assignments.**

```bash
cargo add hns-odoh-protocol
```

The crate is part of the
[`hns-rs`](https://github.com/handshake-rs/hns-rs) workspace and supports Rust
1.89 or later. API documentation is available on
[docs.rs](https://docs.rs/hns-odoh-protocol).
