# hns-dns-relay-protocol

Bounded wire types compatible with the draft Handshake P2P DNS relay.

This crate implements the allocation-bounded request and response messages
described by draft HIP #76.

**The associated Denuo wire assignments are experimental and are not official
Handshake protocol assignments.**

```bash
cargo add hns-dns-relay-protocol
```

The crate is part of the
[`hns-rs`](https://github.com/handshake-rs/hns-rs) workspace and supports Rust
1.89 or later. API documentation is available on
[docs.rs](https://docs.rs/hns-dns-relay-protocol).
