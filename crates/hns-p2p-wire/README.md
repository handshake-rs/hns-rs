# hns-p2p-wire

Runtime-independent standard Handshake P2P framing and packet codecs.

This crate implements bounded HSD-compatible framing, network messages, packet
IDs, stream decoding, and protocol validation. It is part of the
[`hns-rs`](https://github.com/handshake-rs/hns-rs) protocol workspace.

```bash
cargo add hns-p2p-wire
```

The minimum supported Rust version is 1.89. API documentation is available on
[docs.rs](https://docs.rs/hns-p2p-wire).
