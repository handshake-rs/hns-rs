# hns-urkel-proof

Bounded parsing and verification for HSD-compatible Urkel proofs.

This crate handles Handshake name-tree inclusion and non-inclusion proofs in
the HSD wire format, with strict bounds and verification. It is part of the
[`hns-rs`](https://github.com/handshake-rs/hns-rs) protocol workspace.

```bash
cargo add hns-urkel-proof
```

The minimum supported Rust version is 1.89. API documentation is available on
[docs.rs](https://docs.rs/hns-urkel-proof).
